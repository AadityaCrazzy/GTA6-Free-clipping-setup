# 🎮 GTA 6 Free Clipping Setup

A lightweight, completely free setup guide to record, clip, and export high-quality gameplay moments for **Grand Theft Auto VI** with minimal FPS impact.

## 📄 What's Included
* **[GTA6_Clipping_Guide.pdf](./GTA6_Clipping_Guide.pdf)** — Step-by-step instructions covering optimal software choices, replay buffer configuration, bitrate/encoder settings, and hotkey bindings.

## 🚀 Quick Start
1. **Download the Guide:** Click on [`GTA6_Clipping_Guide.pdf`](./GTA6_Clipping_Guide.pdf) in the file list above and select **Download raw file**.
2. **Install Recommended Tools:** Follow Section 1 of the PDF to install the free, open-source recording software.
3. **Configure Replay Buffer:** Apply the encoder and audio-track settings to capture instant replays without filling up your storage drive.
4. **Set Your Hotkey:** Bind your preferred clip key and start capturing.

## ✨ Key Features
* **100% Free:** Uses only free and open-source tools—no watermarks, subscriptions, or paywalls.
* **Low Performance Overhead:** Configured to leverage hardware encoders (NVENC / AMF / QuickSync) so your framerate stays smooth.
* **Instant Replay Ready:** Save the last 30 seconds to 5 minutes of gameplay on demand with a single keypress.
